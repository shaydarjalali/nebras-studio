نسخه اصلاح‌شده سایت نبراس

این فایل‌ها برای جایگزینی مستقیم در مخزن GitHub Pages آماده شده‌اند.

فایل‌ها:
- index.html
- styles.css
- app.js
- assets/cloud-cinematic-v1.webp
- assets/logo.webp

برای پیش‌نمایش محلی، در این پوشه یک سرور استاتیک اجرا کنید:
python -m http.server 8080

سپس http://localhost:8080 را باز کنید.
